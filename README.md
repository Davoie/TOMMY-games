# 🐟 TOMMY 游戏厅

一个纯 HTML/CSS/JS 网页小游戏合集，零依赖，打开即玩。

## 🎮 游戏列表

| 序号 | 游戏 | 操作方式 | 状态 |
|------|------|----------|------|
| 01 | 绿头鱼跳跳 | 空格键 / 点击屏幕 | ✅ 已完成 |
| 02 | 赛车游戏 | ← → 方向键 | 🔜 即将推出 |
| 03 | 雷电飞机 | ← → + 空格发射 | 🔜 即将推出 |
| 04 | 贪吃蛇 | ↑ ↓ ← → 方向键 | 🔜 即将推出 |
| 05+ | 超级玛丽类 | 多按键操作 | 🔜 即将推出 |

## 🚀 快速开始

直接在浏览器打开 `index.html` 即可进入游戏大厅。

## 📁 项目结构

```
TOMMY/
├── index.html                  # 游戏大厅入口
├── shared/hub.css              # 大厅样式
├── games/                      # 游戏目录
│   └── 01-green-fish-jump/     # 绿头鱼跳跳
└── assets/                     # 共享资源
```

## 🛠 技术栈

- 纯 HTML5 / CSS3 / JavaScript (ES6+)
- HTML5 Canvas 游戏渲染
- localStorage 数据存储
- 无任何第三方依赖
